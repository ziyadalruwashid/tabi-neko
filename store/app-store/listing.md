# App Store listing

Everything to type into App Store Connect for Tabi Neko 1.0, in English and
Arabic. The screenshots and artwork are in this folder (see `README.md`);
TestFlight setup is in `testflight.md`.

Where things go in App Store Connect (**Apps → Tabi Neko**):

- **App Information** (left menu): name, subtitle, category, privacy
  policy, age rating, and the Arabic version under *Localizable
  Information → Arabic*.
- **Distribution → iOS App → 1.0**: promotional text, description,
  keywords, URLs, screenshots, build, App Review Information.
- **App Privacy** (left menu): the privacy answers below.
- **Pricing and Availability**: Free, all countries.

Limits are Apple's; every text below fits (counts in brackets). Apple
indexes the app name and subtitle for search, so the keywords don't repeat
them.

## App Privacy

**Do you or your third-party partners collect data from this app?** Yes.
**Tracking:** No, for every type (nothing is used to track people across
other companies' apps or websites).

Tick only these types. All are **linked to the user** (they belong to the
account) and **not used for tracking**.

| Data type | Purposes | What it is |
|---|---|---|
| **Contact Info → Email Address** | App Functionality | The login email |
| **Contact Info → Name** | App Functionality | The optional display name |
| **User Content → Other User Content** | App Functionality | Trips, stamps, where you're staying, and Apollo answers you report |
| **Identifiers → User ID** | App Functionality | The account's ID, to keep its trip and stamps |
| **Usage Data → Product Interaction** | App Functionality, Analytics | Apollo's daily question count (for the 10-a-day limit), and when the account last signed in and how (Google or email), for the owner's dashboard |

Don't tick:

- **Location**: used only on the phone (distances, near me, stamps). Apple
  counts data that never leaves the device as not collected.
- **Photos**: Halal Lens reads the photo on the phone, it's never uploaded.
- **Search History, Messages**: hotel searches and questions to Apollo are
  sent to answer them, then not kept, so they're not "collected" in Apple's
  sense (data handled only in real time).
- **Diagnostics, Purchases, Financial, Health, Contacts, Browsing**: none.

Total visits and app opens are one number per day with nothing about the
person (no ID, no cookie, no IP), so they're not user data either.
